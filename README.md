# Lot Tracker

Lot Tracker for David's Auto Sales — Lot 9, Lot 12, and AAA inventory.

## Open on iPhone

1. Open the site in **Safari**
2. Tap **Share**
3. Tap **Add to Home Screen**

That installs Lot Tracker as a home-screen app.

## Rebuild

Run `python3 build.py` to regenerate `index.html` from `index.template.html` and `seed.json`.
